## What each app does

**Daily Quotes.** A new quote every day across motivation, psychology, faith, wisdom and leadership. Save quotes, add personal reflections, see author photos and biographies, get a daily notification, listen to quotes, track a streak, and share quotes as images.

**Expense Tracker.** Log expenses with amount, category, note and date. History grouped by day, search and filters, category breakdown, last 7 days chart, monthly budget with warnings, and a PDF report export.

**To-Do with Reminders.** Add, edit, delete and complete tasks. Local notification reminders at a set time, progress bar, filters, undo after delete, and dark and light themes.

## Run any app locally

```bash
cd daily-quotes-app      # or expense-tracker-app, or todo-reminders-app
npm install
npx expo start
```

Scan the QR code with Expo Go. Notifications (Quotes and To-Do) only work in the installed APK, not in Expo Go.
